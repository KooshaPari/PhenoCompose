# PhenoCompose i18n & a11y

i18n via `fluent` + a11y via `tui-input`/`crossterm` best practices.

## Stack

- `fluent` v0.16+ - Mozilla's FTL parser (ICU MessageFormat)
- `fluent-bundle` - bundle loader
- `unic-langid` - language identifiers (BCP-47)
- `crossterm` - terminal a11y (screen reader, high contrast)

## Translation bundles

`crates/i18n/locales/<lang>/<component>.ftl`:

```ftl
# en-US/manifest.ftl
manifest-name = Manifest name
manifest-validation-failed = Validation failed: { $reason }
sandbox-create-success = Sandbox { $name } created in { $duration }s
```

`crates/i18n/locales/es-ES/manifest.ftl`:

```ftl
manifest-name = Nombre del manifiesto
manifest-validation-failed = Validación fallida: { $reason }
sandbox-create-success = Arenero { $name } creado en { $duration }s
```

## Usage

```rust
use phenocompose_i18n::{I18n, Bundle};

let i18n = I18n::load(&["en-US", "es-ES", "ja-JP"]).await?;
let s = i18n.format("es-ES", "sandbox-create-success", &[("name", "test"), ("duration", 5)]);
println!("{}", s);  // "Arenero test creado en 5s"
```

## Locale fallback

`en-US` is the default. If a key is missing in a target locale, fallback to `en-US`. If also missing in `en-US`, log a warning and return the key name.

## CLI a11y

```rust
use crossterm::{
    style::{Color, Attribute, ResetColor, SetAttribute, SetForegroundColor},
    event::{KeyCode, KeyEvent, KeyEventKind, KeyModifiers},
};

// Always pair visual indicators with text labels
println!("{} Sandbox created", 
    SetForegroundColor(Color::Green),  // not just color - always also text
    ResetColor,
);

// Don't rely on color alone
let marker = if success { "[OK]" } else { "[FAIL]" };  // text marker
println!("{marker} Sandbox created");
```

## Screen reader support

```rust
println!("\x1b[?8002h");  // enable bracketed paste (helps screen readers)
```

## High contrast

- Respect `NO_COLOR` env var
- Honor `TERM=dumb` (no colors)
- Detect `COLORTERM=truecolor` vs `COLORTERM=24bit`

## Translation test

```rust
#[test]
fn test_sandbox_create_translation() {
    let i18n = I18n::load(&["en-US", "es-ES"]).await.unwrap();
    assert_eq!(
        i18n.format("es-ES", "sandbox-create-success", &[("name", "x"), ("duration", 1)]),
        "Arenero x creado en 1s"
    );
}
```

## Coverage target

- 100% of user-facing strings in `crates/i18n/locales/en-US/`
- Each non-en-US locale covers at least 80% of en-US keys
- CI fails PR if locale coverage drops
