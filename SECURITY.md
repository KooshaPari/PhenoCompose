# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| main    | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Email security@phenotype.example.com (PGP key on request) or open a private security advisory on GitHub.

We aim to:
- Acknowledge within 48 hours
- Triage within 7 days
- Patch critical issues within 30 days

## Disclosure

We follow [coordinated disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure):
- Reporter gives us 90 days before public disclosure
- We work with the reporter on a fix and coordinated announcement
