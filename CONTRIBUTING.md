# Contributing to PhenoCompose

Thanks for contributing to PhenoCompose. This repository follows the Phenotype
monorepo contribution rules in [../CONTRIBUTING.md](../CONTRIBUTING.md).

## Make Your First PR

1. Fork or branch from `main`.
2. Keep the change focused on one bug, feature, or documentation improvement.
3. Run the relevant checks before opening a pull request.
4. Describe what changed, how you tested it, and any follow-up work.

## Development Notes

- Keep changes small and reviewable.
- Preserve existing formatting and naming patterns.
- Add or update tests when behavior changes.
- Do not commit secrets, local credentials, or generated private artifacts.
